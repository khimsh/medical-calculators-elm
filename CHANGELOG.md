# Changelog

All notable changes to this project are recorded here. Versions follow [Semantic Versioning](https://semver.org/).

## 1.0.0 - 2026-10-25

First release, for testing only. Not for clinical use.

- Pill dosage calculator.
- Liquid dosage calculator.
- IV infusion rate calculator: pump rate (mL/h) and drip rate (drops/min).
- Nutrition calculator.
- Free water deficit calculator.
- All calculators grouped under Medication dosing, Fluids & electrolytes, and Nutrition.
- Favorites page, with favorites stored in the browser.
- Georgian and English interface, with a language toggle.
